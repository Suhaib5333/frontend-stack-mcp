# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work, and do not harass anyone. Maintainers may remove comments, commits, issues or contributors that break these rules.

To report a problem, use [private reporting](https://github.com/Suhaib5333/frontend-stack-mcp/security/advisories/new) or contact the maintainer through their GitHub profile. Reports are handled confidentially.
